# 密码本 · macOS 使用说明

一本摊在桌上的手写密码本：输主密码解锁 → 翻开本子 → 一页写一条密码。
数据用 AES-256-GCM 加密后**只存在你自己电脑里**，不联网、不上传。

---

## 一、下载哪个（先看芯片）

左上角   → 「关于本机」：

| 你的芯片 | 下载这个 |
| --- | --- |
| Apple M1 / M2 / M3 / M4 | `password-notebook-1.0.0-arm64-mac.zip`（97 MB） |
| Intel Core i5 / i7 / i9 | `password-notebook-1.0.0-x64-mac.zip`（101 MB） |

下载页（永远指向最新版）：
https://github.com/SgF-123/password-notebook/releases/latest

## 二、安装（30 秒）

1. 双击 zip 解压，把里面的 **密码本.app** 拖进「应用程序」文件夹
2. **第一次打开不要双击**：在 Finder 里**右键**（或按住 Control 点它）→ 选「打开」→ 弹窗里再点一次「打开」。
   以后就能正常双击了。
   （原因：这个包没有 Apple 开发者签名，macOS 会拦第一次。不点这一次的话，系统会一直提示"无法验证开发者"。）
3. 如果提示 **「"密码本"已损坏，无法打开」**，打开「终端」，粘贴这一行回车：

```bash
xattr -dr com.apple.quarantine /Applications/密码本.app
```

---

## 三、第一次用

1. 打开后是解锁页；第一次会让你**创建主密码**（至少 6 位）
2. ⚠️ **主密码忘了就真的打不开了**——设计如此，没有后门、也没法找回，请记牢或自己留个提示
3. 进去之后就是一本本子：封面 → 扉页 → 目录 → 一页一条密码 → 封底

---

## 四、日常怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 写一条新密码 | 底部 **「＋ 写一条」**（或 ⌘N）→ 填标题/账号/密码/网址/备注 → 「保存」；本子会自动翻到新写的那一页 |
| 改一条 | 在本子上**双击**那一条；或翻到那页后点底部「改这条」 |
| 翻页 | 鼠标拖页角（四角都能拖）/ `←` `→` / 底部「上一页 · 下一页」 |
| 跳到某一条 | 点底部「目录」→ 点目录里那一行，直接跳过去 |
| 复制密码 | 直接**点本子上那行密码** → 已复制到剪贴板 |
| 遮住密码 | 底部「遮住密码」（开会、录屏、给别人看屏幕时用） |
| 翻页音效 | 底部「音效：开 / 关」 |
| 合上本子（锁定） | 标题栏 🔒 或 ⌘L |
| 生成一个强密码 | 标题栏 ⚡ → 生成并复制 |
| 改本子署名 | 标题栏 ⚙ → 「本子署名」（印在封面上） |
| 闲置自动锁定 | 标题栏 ⚙ → 「自动锁定」 |

## 五、密码存在哪 / 怎么备份

- 密码库文件：`~/Library/Application Support/密码本/data/vault.dat`
  （在访达里按 ⇧⌘G，粘贴这个路径就能直接到）
- **备份**：把这个 `vault.dat` 拷到 U 盘 / 网盘就行。它是**整库密文**，必须配合主密码才能打开。
- **换电脑**：把 `vault.dat` 拷到新机器的同一路径，用同一个主密码解锁即可。

## 六、可能遇到的

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 「无法打开，因为 Apple 无法检查其是否包含恶意软件」 | 正常现象（未签名）。右键 →「打开」；或跑上面那行 `xattr` |
| 图标上有个小斜杠 / 双击没反应 | 可能没解压就点了，或者系统版本太老（需要 macOS 11 及以上） |
| 忘了主密码 | 打不开了。只能删掉 `vault.dat` 重新开始（密码本人也解不开） |
| 想彻底卸载 | 把「应用程序」里的 密码本.app 拖进废纸篓；想连密码一起清掉，再删掉上面那个 `vault.dat` |

## 七、它是怎么做的（给好奇的人）

Electron 外壳 + turn.js 仿真翻页；界面是自绘标题栏 + 嵌进窗口的手写本子；
加密是 scrypt 派生密钥 + AES-256-GCM。
这两个包是在 Windows 上跨平台打出来的：官方 `@electron/packager` 生成 .app，
再用仓库里的 `work/pack-mac.js` 自己写 zip（**保留 macOS 框架的符号链接、可执行位和 UTF-8 文件名**，
Windows 自带压缩工具会把这三样弄坏），并修正了 `Info.plist` 的图标 / 分类 / asar 完整性校验键。

源码与更新：https://github.com/SgF-123/password-notebook
